# lazeefirerider Website

Starter website for `lazeefirerider.com`.

## Chosen Setup

This first version uses plain HTML, CSS, and JavaScript with no required npm packages.

Why this choice:

- Simple to upload to Bluehost.
- Easy to open locally in a browser.
- No build step to break.
- GitHub-friendly.
- Easy for Codex to extend later.

Available local tooling checked on 22 May 2026:

- Node.js: installed.
- npm: installed, but PowerShell blocks `npm.ps1`; `cmd /c npm ...` works.
- pnpm: not installed.
- yarn: not installed.
